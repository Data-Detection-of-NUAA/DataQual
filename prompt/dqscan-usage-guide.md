# dqscan 使用流程（前端操作 + 参数说明）

本文面向“表格数据（CSV/TXT）”的 dqscan 使用流程与参数说明，与你现在的前端交互保持一致。

---

## 1. 完整扫描流程（推荐）

1) 选择数据模态
- 选择“表格数据”。

2) 上传文件
- 选择“分布偏差对比方式”：
  - 基线文件 vs 当前文件（推荐）：必须上传基线文件。
  - 仅当前文件（免基线）：系统按“切分比例”自动模拟对比。
- 上传当前文件（必传），如选择基线方式则上传基线文件。

3) 选择算法（核心配置区）
- 先在每个模块的“基础参数”完成通用配置。
- 再在“缺陷绑定”里为每个缺陷选择“执行算法”。
- 最后在“算法参数”里根据已绑定算法补充对应参数。

4) 开始检测
- 如果有缺陷未绑定算法、基线模式未上传基线、Label Shift 未选标签列，系统会阻止启动。

5) 查看结果
- 结果页支持报告视图（JSON/摘要）和产物下载（docx/json/summary）。

---

## 2. 推荐勾选组合（“全量检测”）

**缺陷勾选（左侧树）**
- 脏数据：异常样本、缺失值异常、重复/近重复、值域违规
- 分布偏差：数值特征漂移、类别特征漂移（如有标签列再勾标签分布变化）
- 对抗性：黑盒攻击（ZOO/随机）
- 物理保真度：Schema 校验、守恒/一致性校验

**执行算法绑定（右侧-缺陷绑定）**
- 脏数据：
  - 异常样本 → 通用脏数据扫描器（ECOD + 3σ）
  - 缺失值异常 → 缺失统计 + 阈值
  - 重复/近重复 → 完全重复检测
  - 值域违规 → 3σ 规则
- 分布偏差：
  - 数值特征漂移 → MMD + KS + 卡方（两样本）
  - 类别特征漂移 → MMD + KS + 卡方（两样本）
  - 标签分布变化 → MMD + KS + 卡方（两样本）
- 对抗性：
  - 黑盒攻击 → ZOO（ART）/ 随机扰动
- 物理保真度：
  - Schema 校验 → Pandera Schema / 基础校验
  - 守恒/一致性校验 → 跨字段约束（守恒/一致性）

## 3. 算法说明（当前“可用”部分）

- **MMD + KS + 卡方（两样本）**
  - 对数值列做 MMD/KS，对类别列做卡方检验，输出漂移结论和 p 值。

- **通用脏数据扫描器（ECOD + 3σ）**
  - 一次扫描输出异常/缺失/重复/值域违规；有 pyod 时用 ECOD，无依赖则降级为 3σ。

- **缺失统计 + 阈值**
  - 统计每列缺失率；超过阈值的列会被标记为异常。

- **完全重复检测**
  - 按整行或关键字段判断重复，输出重复率与示例行。

- **3σ 规则**
  - 通过均值±kσ 的启发式规则定位异常取值范围。

- **ZOO（ART）/ 随机扰动**
  - 有 ART 则执行 ZOO 黑盒攻击；无 ART 则用随机扰动降级。

- **Pandera Schema / 基础校验**
  - 有 pandera 则用 schema 校验；无依赖则降级为 min/max 规则校验。

- **跨字段约束（守恒/一致性）**
  - 启用输入输出守恒等跨字段启发式规则。

> 标记为“即将上线”的算法仅展示，当前版本不可执行。

## 4. 参数配置说明（与页面一致）

### 4.1 分布偏差（Distribution）
**基础参数**
- 对比方式：基线文件对比 / 免基线切分模拟
- 切分比例：免基线时用于拆分 train/test 的比例
- 排除字段：如 ID/时间戳等天然会变化的列

**算法参数（MMD + KS + 卡方）**
- p 值阈值（p_val）：越小越严格
- 标签列（Label Shift）：用于标签分布变化检测

### 4.2 脏数据（Dirty Data）
**基础参数**
- 输出样例数：报告中最多展示多少个问题样本
- 白名单/黑名单字段：控制扫描范围（可选）

**算法参数**
- 异常率/污染度（contamination）：异常检测阈值
- 缺失阈值（missing_threshold）：缺失率超过该值才告警
- 重复阈值（duplicate_threshold）：重复率超过该值才告警
- 关键列（去重）：按关键字段判断重复（可选）
- 值域规则：
  - 方法（sigma / iqr）
  - k 值（sigma）
  - IQR 因子（iqr）
  - 仅检查字段（可选）

### 4.3 对抗性（Adversarial）
**基础参数**
- 最大样本数（max_samples）：参与攻击评估的样本上限
- 随机种子（seed）：保证可复现实验

**算法参数（ZOO/随机）**
- 扰动预算（epsilon）
- 最大迭代（max_iter）
- 随机尝试次数（random_trials）
- 随机特征数（random_features）
- 学习率（learning_rate）
- 置信度（confidence）
- Batch Size

### 4.4 物理保真度（Physics）
**算法参数**
- 自动推断约束（auto_constraints）：开启后自动补充 age/price/rate 等启发式规则
- 字段约束表：自定义 min/max 规则
- 守恒/一致性校验（check_conservation）：启用跨字段守恒规则

---

## 5. 注意事项与建议

- **Label Shift** 必须指定标签列，否则无法执行。
- **基线对比模式** 必须上传基线文件。
- “即将上线”能力仅展示，不会参与实际扫描。
- 如需更严格扫描，建议：
  - p_val 设置更小
  - missing/duplicate 阈值设置更低
  - 开启跨字段守恒规则与自定义 min/max 约束
