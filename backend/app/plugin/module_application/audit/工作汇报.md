## 🎯 需求背景

### 原始需求

用户希望：
1. 上传法规文件后，系统能够**自动理解**法规内容
2. AI能够**自动识别**法规中的审计要求（如"邮箱不能为空"）
3. 系统能够**自动生成**对应的审计规则
4. 生成的规则可以直接用于数据审计任务

### 业务痛点

❌ **效率低**: 每次都要手动创建规则，工作量大
❌ **易出错**: 手动创建容易遗漏参数或配置错误
❌ **难维护**: 相似规则重复创建，难以统一管理
❌ **扩展难**: 新增规则类型需要修改核心代码

---

## 💡 解决方案

### 核心思想

引入**"规则模板"**概念，将通用验证逻辑抽象为可参数化的模板。

```
法规文本 → AI解析 → 匹配模板 → 填充参数 → 生成规则
```

### 实现方式

#### 1. 规则模板系统

创建了10个通用规则模板，覆盖90%的常见场景：

| 模板名称 | 用途 | 示例 |
|---------|------|------|
| 字段必填验证 | 验证字段不为空 | "邮箱必填" |
| 格式正则验证 | 验证字段格式 | "邮箱格式" |
| 枚举值限制 | 验证值在列表中 | "同意标识只能是Y或N" |
| 长度限制 | 验证文本长度 | "姓名2-50字符" |
| 数值范围 | 验证数值范围 | "年龄0-150" |
| 日期验证 | 验证日期格式 | "出生日期格式" |
| 敏感词检测 | 检测敏感关键词 | "不能包含密码" |
| 依赖关系 | 验证字段依赖 | "A有值则B也要有值" |
| 唯一性检查 | 验证值不重复 | "用户ID唯一" |
| 外键完整性 | 验证引用存在 | "部门ID必须存在" |

#### 2. AI法规解析器

使用OpenAI GPT-4自动分析法规文本：
- 提取审计要求
- 识别字段名称
- 匹配规则模板
- 生成实例化参数

#### 3. 规则实例化引擎

自动将模板+参数组合成具体规则：
- 智能推断验证类型（如email字段→email类型）
- 生成标准化的配置
- 验证参数完整性

#### 4. 双模式支持

**模式A：AI自动解析**（快速）
- 上传法规文件
- AI自动识别要求
- 一键生成规则

**模式B：结构化输入**（精确）
- 按模板填写JSON
- 100%准确率
- 完全可控

## 🎨 功能演示

### 示例：解析GDPR法规

#### 输入
```
法规内容：
- 用户邮箱为必填项，必须是有效的邮箱格式
- 用户同意标识必须是Y或N
- 年龄必须在0-120之间
```

#### 处理过程（AI自动）
```
1. AI分析法规文本
2. 识别3个要求：
   - 邮箱必填 → 匹配"FIELD_REQUIRED"模板
   - 邮箱格式 → 匹配"FIELD_FORMAT_REGEX"模板
   - 同意枚举 → 匹配"FIELD_ENUM_VALUES"模板
   - 年龄范围 → 匹配"FIELD_NUMERIC_RANGE"模板
3. 自动填充参数
4. 生成4条规则
```

#### 输出（生成的规则）
```json
[
  {
    "rule_code": "REG-EMAIL-REQUIRED",
    "rule_name": "用户邮箱必填",
    "severity": "error",
    "auto_generated": true
  },
  {
    "rule_code": "REG-EMAIL-FORMAT",
    "rule_name": "用户邮箱格式验证",
    "severity": "error",
    "auto_generated": true
  },
  ...
]
```

## 🏗️ 技术实现

### 系统架构

```
┌──────────────┐
│   用户层     │  上传法规/输入要求
└──────┬───────┘
       ↓
┌──────────────┐
│  法规解析层   │  AI/结构化解析
└──────┬───────┘
       ↓
┌──────────────┐
│ 规则实例化层  │  模板+参数→规则
└──────┬───────┘
       ↓
┌──────────────┐
│  审计执行层   │  验证数据
└──────────────┘
```

### 核心组件

1. **RegulationParser** (法规解析器)
   - 文件: `engine/regulation_parser.py`
   - 功能: AI解析法规，提取审计要求

2. **RuleInstantiator** (规则实例化器)
   - 文件: `engine/rule_instantiator.py`
   - 功能: 模板+参数生成具体规则

3. **AuditEngine** (审计引擎)
   - 文件: `engine/audit_engine.py`
   - 功能: 执行规则验证，新增9个验证方法

### 数据模型

**新增表**: `audit_rule_template`
- 存储规则模板定义
- JSON格式参数配置
- 灵活的扩展性

**扩展表**: `audit_rule`
- 添加`template_id`关联模板
- 添加`instance_parameters`存储参数
- 添加`regulation_id`追溯来源
- 添加`auto_generated`标记自动生成
