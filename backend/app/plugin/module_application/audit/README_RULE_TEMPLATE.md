## ✨ 核心特性

### 1. 规则模板系统
- 10个默认模板
- 覆盖90%常见场景
- 灵活可扩展

### 2. AI法规解析
- 自动提取审计要求
- 智能模板匹配
- 支持多种文件格式

### 3. 规则自动生成
- 一键生成规则
- 参数自动填充
- 智能类型推断

### 4. 双模式支持
- AI自动解析（快速）
- 结构化输入（精确）
