# 前端代码迁移说明

## 迁移日期
2026-01-22

---

## 迁移原因

按照 [开发规范.md](../../../开发规范.md) 要求，统一前端代码组织结构：

> 前端模块写在：`frontend/src/`
> - 页面：`frontend/src/views/module_application/<模块名>/index.vue`
> - API 封装：`frontend/src/api/module_application/<模块名>.ts`

---

## 迁移内容

### Dataset 模块

**旧路径:**
- 视图: `views/module_dataset/dataset/`
- API: `api/module_dataset/dataset.ts`

**新路径:**
- 视图: `views/module_application/dataset/`
- API: `api/module_application/dataset.ts`

**文件列表:**
- `views/module_application/dataset/index.vue` - 数据集管理主页面
- `views/module_application/dataset/components/DatasetUpload.vue` - 上传组件
- `views/module_application/dataset/components/DatasetAnalysis.vue` - 分析组件
- `api/module_application/dataset.ts` - Dataset API 封装

---

### Train 模块

**旧路径:**
- 视图: `views/module_dataset/robustness/` (原鲁棒性评估)
- API: `api/module_train/model.ts`

**新路径:**
- 视图: `views/module_application/train/`
- API: `api/module_application/train.ts`

**文件列表:**
- `views/module_application/train/index.vue` - 模型推荐/训练主页面
- `views/module_application/train/components/ModelRecommendation.vue` - 模型推荐组件
- `api/module_application/train.ts` - Model/Train API 封装

---

## 导入路径变更

### API 导入

```typescript
// 旧写法
import DatasetAPI from "@/api/module_dataset/dataset";
import { ModelAPI } from "@/api/module_train/model";

// 新写法
import { DatasetAPI } from "@/api/module_application/dataset";
import { ModelAPI } from "@/api/module_application/train";
```

### 组件导入

```typescript
// 旧写法
import DatasetUpload from "@/views/module_dataset/dataset/components/DatasetUpload.vue";
import ModelRecommendation from "@/views/module_dataset/robustness/components/ModelRecommendation.vue";

// 新写法
import DatasetUpload from "@/views/module_application/dataset/components/DatasetUpload.vue";
import ModelRecommendation from "@/views/module_application/train/components/ModelRecommendation.vue";
```

## 菜单配置

前端页面路径需要在后端菜单表中更新：

### Dataset 菜单

```sql
UPDATE menu
SET route_path = '/application/dataset',
    component_path = 'module_application/dataset/index'
WHERE route_name = 'DatasetManagement';
```

### Train 菜单

```sql
UPDATE menu
SET route_path = '/application/train',
    component_path = 'module_application/train/index'
WHERE route_name = 'ModelRecommendation' OR route_name = 'RobustnessEvaluation';
```
